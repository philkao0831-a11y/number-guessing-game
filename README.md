# number guessing game
A simple Python number guessing:
這是一款成功逗樂七歲小女孩的 Python 互動猜數字遊戲！系統會隨機生成 1 到 100 的數字，並根據玩家的輸入給予『太高』或『太低』的即時提示，引導玩家一步步運用邏輯縮小範圍找尋解答。老少咸宜，適合所有人來測試自己的運氣與推演能力。

核心功能:
-隨機生成：系統每次遊玩都會自動使用 random 模組產生 1 到 100 的未知數字。
-智慧提示：根據玩家輸入的數字，給予「猜高一點」或「猜低一點」的精準反饋。
-次數追蹤：遊戲會自動記錄玩家成功破關所花費的總猜測次數，增加挑戰趣味性。

使用技術：Python 3

核心語法：
while 迴圈控制遊戲進程與玩家重新輸入機制。
if / elif / else 條件判斷式處理邏輯判斷。
input() 收集玩家輸入並進行資料型態轉換 (int)。
f-string 動態格式化輸出最終成績。

執行畫面:
小朋友，猜猜看，我心裡想的數字是多少?: 
猜錯啦! 猜高一點!
小朋友，猜猜看，我心裡想的數字是多少?: 
不對! 猜低一點
恭喜你，猜對了！
你總共猜了 次!
